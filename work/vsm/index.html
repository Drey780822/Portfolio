VSM: Building a More Connected Event-Services Platform

VSM explores how photography and videography bookings, flexible pricing, and financing options can be brought together within a single business platform. The project combines customer-facing service discovery with the operational systems needed to manage bookings, customers, payments, and related workflows.

Role

Lead Full-Stack Systems Developer

Core Stack

Next.js 15.5 · React 19 · Supabase

Current Phase

Pre-Launch Development

Guiding Principle

Two Services. One Platform.

1. The Problem VSM Addresses

Traditional event photography services often present customers with rigid, fixed packages that do not suit every event or budget. Someone planning an intimate birthday, baby shower, graduation, or pool party may need only one or two hours of coverage. In contrast, a wedding, funeral, or corporate conference requires multi-camera production and comprehensive logistics.

Simultaneously, customers face fragmented booking processes, opaque pricing, and lack of visibility into their booking or payment status. On the business side, creative entrepreneurs and photographers struggle to manage enquiries, track bookings, reconcile payments, and manage financing applications without juggling multiple disconnected spreadsheets.

3. How the Platform Works: The Dual Customer Journey

A. Photography & Videography Bookings

The customer journey begins with event discovery. VSM differentiates between smaller, agile events and major milestone productions:

  • Flexible Options for Smaller Events: Designed for birthdays, baby showers, graduations, pool parties, and private social events. Pricing factors include hours required, photo vs. video deliverables, and production extras rather than forcing high fixed costs.
  • Structured Premium Production Packages:
    • Essential Production (R5,500): Core coverage for significant personal celebrations.
    • Cinematic Production (R8,900): Comprehensive multi-angle coverage for larger events.
    • Legacy Production (R14,500): Full-tier production service tailored to major multi-day weddings and prestigious corporate gatherings.

B. Smart Financing Experience

To make milestone event coverage accessible, VSM incorporates a smart financing workflow:

  1. Eligibility Assessment: Customer initiates an eligibility check with basic event and identity details.
  2. Transparent Estimate: System evaluates criteria via server-side logic and returns a dynamic repayment estimate. (Note: Estimates are structured calculations rather than guaranteed credit approvals).
  3. Application & Verification: Customer submits necessary documentation for policy validation.
  4. Connected Repayment Tracking: Approved financing anchors directly to the customer's booking in the unified database.

C. VSM Memory Vault Concept

Post-event, clients receive access to the Memory Vault—a central digital repository designed for viewing, curating, and preserving high-resolution event media:

4. Verified Technical Architecture

An independent code inspection of the VSM-Digital-Services repository confirms the following architectural implementations:

  • Frontend Engine: Next.js 15.5 with React 19, TypeScript, Tailwind CSS, @tailwindcss/forms, and framer-motion.
  • Database & Authentication: Supabase (PostgreSQL) utilizing Row Level Security (RLS) to enforce data boundaries between public booking interfaces and private administrative tables.
  • Implemented Core Services (src/lib/services):
    • eligibility.engine.ts: Evaluates customer financial variables and calculates financing eligibility ranges.
    • bookings.service.ts: Manages booking state transitions, package categorization, and scheduling.
    • loans.service.ts & repayments.service.ts: Models loan records, instalment schedules, and balance tracking.
    • customers.service.ts, invoices.service.ts, packages.service.ts, gallery.service.ts, vaults.service.ts, analytics.service.ts.
  • Verified App Routes (src/app):
    • /book: Step-by-step service customizer and event selector.
    • /loan-application-flow: Multi-stage financing application interface.
    • /admin-dashboard: Administrative console containing dedicated sub-modules for bookings, calendar, loans, repayments, invoices, vaults, and gallery management.
    • /portal & /track: Client self-service and booking tracking.
    • /vault: Digital asset delivery portal.

5. Engineering Challenges & System Design

Engineering Challenge Architectural Resolution
Event-Type Polymorphism Engineered modular schemas capable of handling hourly variable coverage for small shoots alongside fixed-rate production tiers.
Dual-Service Relational Integrity Linked customer records across booking IDs and loan application IDs, ensuring status transitions in financing automatically update event fulfillment state.
Financial Data Security Enforced server-side validation and Supabase Row Level Security (RLS) so that customer identity, loan balances, and repayments cannot be modified client-side.
Integrated Back-Office Operations Unified booking calendar, invoices, loan balances, and media vaults into a single administrative control plane.

6. Project Status & Implementation Boundary

Pre-Launch Transparency: VSM is currently in active pre-launch development. The frontend architecture, database schema, eligibility engine, and administrative workflows are implemented and verified in the codebase. Production live payment gateway processing, automated SMS notifications, and public cloud deployment remain scheduled for upcoming launch milestones.
