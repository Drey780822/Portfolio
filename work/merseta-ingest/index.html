merSETA Layer 0 Ingestion & Mathematical Reconciliation Engine

A mission-critical, fail-closed data ingestion pipeline that ingests, extracts, cleans, mathematically audits, and vaults unstructured South African skills demand and labor market documents before downstream release.

1. Project Context & The Core Problem

In South Africa, governmental labor forecasting, national qualification frameworks, and multi-million rand industrial skills levies depend heavily on unstructured PDF/CSV filings. Sector Education and Training Authorities (SETAs), such as merSETA, process hundreds of complex submissions annually—including Sector Skills Plans (SSPs), Workplace Skills Plans (WSPs), Annual Training Reports (ATRs), and TVET college enrolments.

Historically, extraction pipelines in public planning institutions suffered from three systemic points of failure:

  • OCR and Coordinate Drift: Extracting tabular data from heterogeneous PDFs frequently misaligned column cells, truncated leading negative numbers, or merged adjacent rows.
  • Corrupted Policy Forecasting: Traditional ingestion scripts blindly ingested corrupted figures into downstream machine learning models, leading national skills shortage forecasts to rely on mathematically impossible numbers.
  • Auditor-General Compliance Failure: Extraction workflows lacked verifiable cryptographic provenance, failing to meet the strict non-repudiation standards of the Auditor-General of South Africa (AGSA).

2. The Fail-Closed Engineering Philosophy

The core architectural tenet of merseta-ingest is: Mathematical accuracy over ingestion volume.

Unlike conventional web crawlers or loose ETL pipelines that prioritize high completion rates, this engine operates on a strict fail-closed policy. It is vastly preferable to reject 10 ambiguous documents for human review than to permit a single mathematically false line item to enter national skills intelligence models.

The Zero-Float Mandate: Standard IEEE 754 floating-point types (e.g. standard Python float) are strictly forbidden across financial, headcount, and ledger calculations. All calculations use Python's exact Decimal module with a deterministic ROUND_HALF_UP rounding policy.

  1. Document Ingestion & Dropzone Watcher: Monitors inbound dropzone directories with a custom 2-probe file copy stability heuristic (sampling file size over a 500ms backoff) to avoid ingesting partial or locked files during OS network transfers.
  2. Cryptographic Pre-Hashing: Computes the SHA-256 checksum immediately upon detection—before any extraction or parsing begins—to guarantee content-addressed storage and non-repudiation.
  3. Immutable Vault Storage: Persists the original file in Supabase Storage under raw-unstructured/{YYYY}/{sha256}.{ext} while registering an initial tracking record in PostgreSQL (layer0.raw_documents).
  4. Vector vs. Raster Triage (Page Router): Analyzes the internal PDF drawing tree with PyMuPDF (GRID_DRAWING_THRESHOLD >= 8) and character density metrics to distinguish digitally native tables from scanned image fallbacks (OCR_FALLBACK).
  5. Precision Table Extraction: Utilizes pdfplumber bounding boxes to isolate cell structures and headers deterministically.
  6. Domain Schema Mapping: Normalizes South African Organising Framework for Occupations (OFO) codes, standardizes NQF levels, and maps aliases against strict Pydantic v2 domain schemas.
  7. Mathematical Watchdog (The Reconciliation Bridge):** Performs strict arithmetic verification between printed table totals and computed row sums using exact Python Decimal math. It disambiguates subtotals from grand totals and quarantines any table where an individual row fails validation—even if remaining rows accidentally sum to the total.
  8. Fail-Closed Publication Gate: Only documents achieving VERIFIED_AUTO are eligible for downstream release. Mismatched or ambiguous documents are quarantined to STAGED_FOR_REVIEW with an exact arithmetic delta logged.
  9. Crash-Resilient Downstream Dispatch: Implements a durable two-phase publish pattern. Marks PUBLICATION_PENDING in the database before initiating the HTTP push to the downstream Rust analytics orchestrator. If a network timeout occurs, status shifts to PUBLICATION_UNCERTAIN and halts—forbidding blind retries to prevent duplicate data corruption.
  10. Post-Reconciliation Metadata Synchronisation: Automatically updates vault metadata (verification_status, page_count, checksum_delta) to maintain 100% database parity with the authoritative Layer 0 schema.

4. Key Architectural Decisions & Trade-Offs

Decision Alternative Rejected Engineering Justification
Python Decimal Math Native IEEE 754 float Eliminates binary floating-point drift (e.g. 0.1 + 0.2 != 0.3). Essential for government audit compliance and financial levy totals.
2-Probe File Watcher Instant Event Trigger Prevents parsing half-copied files during heavy operating system multi-megabyte transfers over SMB/NFS mounts.
Two-Phase DB Commit Immediate HTTP Retry Prevents duplicate insertion into the downstream Rust orchestrator during packet drops or transient timeouts.
PyMuPDF Vector Tree Uniform OCR for All Pages 12x faster execution by reserving expensive OCR vision models strictly for scanned documents while parsing digital PDFs natively.

  • Defensive Systems Protection: Integrated SSRF guardrails and DNS-pinning mitigations on all external HTTP requests.
